# Study Materials Repository

Welcome to my study materials repository for **Compiler Design**!

## Introduction

This repository contains study materials, notes, and resources related to my Compiler Design course. It's a collection of files that I've found useful for studying and understanding different concepts in the subject. You can ignore this repo if you are not from my class or batch.

## Contents

- **Lexical analysis** - Tokenizers and lexers
- **Syntax analysis** - Parsers and grammar implementations
- **Intermediate code generation** - Three-address code examples
- **Code optimization** - Basic optimization techniques
- **Symbol tables** - Variable management systems
- **Error handling** - Error detection and recovery
- **Complete implementations** - Integrated compiler components
- **Sample code snippets** - Ready-to-compile C++ programs

## How to Use

**Clone the repository:** You can download this repo and study yourself.

**Navigate the contents:** You'll find different folders for various topics and types of files. Feel free to explore and use what you need.

**Compile and run:**

```bash
g++ -o program_name folder/file.cpp
./program_name
```

**Contributions:** If you have your own study materials to share or improvements to suggest, feel free to create a pull request.

## Sample Usage

**Input:** `a + b * ( c - d ) / e`

**Output:**

```
Tokens: [a, +, b, *, (, c, -, d, ), /, e]
Syntax: Valid
Postfix: a b c d - * e / +
```
